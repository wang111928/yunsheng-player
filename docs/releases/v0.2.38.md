# 云声 0.2.38

发布日期：2026-10-09。版本代码：238。

## 更新内容

本版包含自 0.2.29 以来的离线播放及播放体验修订：

- 完整缓存的歌曲可以断网播放，也可在清理后台、重启应用后继续使用已有缓存。离线时，未完整缓存的歌曲灰显并显示清楚的不可播放原因。
- 播放音频缓存不设应用容量上限，不按使用时间自动淘汰。缓存保存在应用私有持久目录，旧缓存自动尝试迁移；设备剩余存储仍是实际限制。清理内容缓存不会删除音频，卸载或清除应用数据会删除音频。
- 修正歌曲自然结束后的自动续播、切换不可离线播放歌曲时的状态处理及播放按钮状态；恢复应用内底部小播放条。
- 点击“上一首”始终切换队列前一曲，不再因当前曲播放超过三秒而重播当前曲。
- 设置增加“软件更新 → 自动更新”。点击后检查本仓库最新正式版本，展示说明和下载进度，校验安装包并交给 Android 确认安装；包含失败重试、重复下载保护与取消清理。
