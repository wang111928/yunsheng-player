# 云声 0.2.42

版本代码：242。构建日期：2026-10-11。GitHub 正式版。

## 本次更新

- 修复 QQ 登录只显示拉起页的问题：官网生成的 QQ 授权入口使用适合手机的页面模式，原生按钮可正常打开 QQ。
- 修复 QQ 授权后进入浏览器的问题：在 Android 允许云声处理 `ssl.ptlogin2.qq.com` 后，接收受限 HTTPS 返回并交回原 WebView，再使用原 Cookie 会话调用官方账号接口验证登录。
- 取消授权后可再次发起；避免重复点击打开多个授权页，避免对带一次性授权票据的返回页面重复加载。
- “授权跳转设置”说明 QQ 所需的 Android 打开链接设置。未启用该设置、缺少兼容 WebView 或未安装 QQ 时，保留官网登录流程。
- 微博跳转限制为官方授权页生成的链接和已安装的微博应用；其他登录继续使用官网已有方式。
