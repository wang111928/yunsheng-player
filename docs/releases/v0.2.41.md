# 云声 0.2.41

发布日期：2026-10-10。版本代码：241。

## 本次更新

本版累计包含 0.2.39–0.2.41 的改进，接续此前正式发布的 0.2.38：

- 睡眠定时器改为小时／分钟滚轮，选中数字居中放大，滑动自动吸附；支持 1 分钟至 24 小时。15／30／60 分钟快捷设置改成同排按钮，保留当前歌曲结束后暂停和取消定时。状态卡显示大字倒计时，沿用当前主题与按压回弹，适配系统字号。
- 设置增加音频缓存占用、完整／部分缓存曲目数与剩余存储统计；独立保存离线歌单目录。音频缓存仍不设应用容量上限、不自动淘汰，清理内容缓存不删除音频。
- 增加单首歌曲收藏到自建歌单，歌单内搜索与显示排序，以及自建歌单改名、简介编辑和批量移除。
- 导入草稿按账号保存，保留来源、图片匹配证据、选择、目标及已完成的写入批次；恢复时检查歌单已有成员，减少重复导入。
- 更新下载状态由应用统一持有，离开页面可继续下载；已完成的安装包重开后重新校验，未完成任务可以重试。重试从头下载，不是按字节断点续传。
- 修订歌词随播放进度自动跟随；日推和风格推荐适配主题，背景增加淡雅／均衡／浓郁三档。
- 第三方登录继续保留官网流程，QQ 增加直接授权入口及返回校验；完整授权回跳仍需实机验证，不表示所有登录方式已自动回跳。
