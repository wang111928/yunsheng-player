# 云声

云声是一个面向 Android 的第三方音乐客户端项目，提供完整的 Gradle 源码结构、架构说明和 Full arm64 安装包。

> 本项目与网易公司及网易云音乐官方无隶属或背书关系。登录、曲库、播放地址等能力依赖第三方服务接口，接口变化可能影响使用。

## 本版变化

0.2.42 增加并修订以下授权流程：

- QQ 授权在系统允许云声打开 `ssl.ptlogin2.qq.com` 后，可从官方页面进入 QQ、完成授权并自动返回云声首页；取消后可以重新发起。
- 授权返回仅在同一会话的 5 分钟内处理一次，并继续使用原页面的 Cookie 会话调用官方账号接口验证登录结果。带一次性授权票据的返回页面不会被应用重复加载。
- 其他账号方式保留官网原有网页流程。不同服务和设备的跳转能力由各服务方与 Android 的链接处理规则决定，项目不承诺全部方式自动回跳。

0.2.41 累计包含 0.2.39–0.2.41 的改进：

- 睡眠定时器使用小时／分钟滚轮，选中项居中放大并自动吸附；支持 1 分钟至 24 小时，保留 15／30／60 分钟快捷设置、当前曲结束后暂停与取消。大字倒计时、主题配色和按压回弹统一呈现。
- 增加音频缓存统计与离线歌单目录。音频缓存仍不设应用容量上限、不自动淘汰；实际空间受设备剩余存储限制，卸载或清除应用数据会删除音频。
- 支持单曲收藏到自建歌单、歌单搜索与显示排序，以及自建歌单改名、简介和批量移除。
- 导入草稿按账号持久化，保留匹配证据、选择与写入检查点；恢复时检查已有成员。
- 更新下载可在离开页面后继续，完整安装包重开后重新校验，未完成任务可重试；重试从头下载。
- 修订歌词进度跟随，推荐页跟随主题，背景有淡雅／均衡／浓郁三档。

更新内容、授权跳转与验证范围见 [0.2.42 版本说明](docs/releases/v0.2.42.md)。历史版本保留在 Releases 中。既有完整缓存离线播放、离线灰显、自动续播、小播放条及上一首切歌行为继续保留。

## 项目结构

项目由 `app`、`shared`、`network-core`、`data-core`、`design-system`、`player-core`、`lyric-engine` 七个 Gradle 模块组成。职责和功能入口见[架构与源码说明](ARCHITECTURE.md)。

## 本机构建

需要 JDK 17 和 Android SDK 36。Windows PowerShell：

```powershell
.\gradlew.bat :app:assembleFullDebug
```

APK 输出在 `app/build/outputs/apk/full/debug/`。设备分发配置只打包 arm64-v8a，不提供 Min 或 x86 安装包。

应用更新器识别正式 Release 附件 `Yunsheng-full-v版本-vc版本号-arm64-v8a.apk`；维护者应使用递增的 versionCode 和同一签名发布新版本。自行构建生成的其他签名 APK 无法覆盖当前分发包。
